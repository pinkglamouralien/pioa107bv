# Лабораторная работа №3

## Тема

Разработка системы управления данными ресторана с использованием объектно-ориентированного программирования.

## Цель работы

- Освоить применение принципов объектно-ориентированного программирования при проектировании программных систем. 
- Приобрести практические навыки переработки существующего программного кода с использованием объектно-ориентированного подхода. 
- Освоить основы автоматизированного тестирования программного обеспечения. 
- Научиться оценивать качество тестового покрытия программы.

---

## Описание проекта

В рамках лабораторной работы разработана система управления данными ресторана, функционирующая в оперативной памяти (In-Memory Database).

Программа позволяет хранить и обрабатывать информацию о:

- гостях ресторана; 
- блюдах меню; 
- заказах.

Реализованы основные CRUD-операции, обработка ошибок, сортировка записей и автоматизированное тестирование.

Предметная область включает следующие сущности:

### Guests (Гости)

Хранит информацию о посетителях ресторана.

Поля записи:

- `id` — уникальный идентификатор гостя; 
- `name` — имя гостя;
- `phone` — номер телефона.

### Dishes (Блюда)

Хранит информацию о блюдах ресторана.

Поля записи:

- `id` — уникальный идентификатор блюда; 
- `name` — название блюда; 
- `price` — стоимость блюда.

### Orders (Заказы)

Хранит информацию о заказах.

Поля записи:

- `id` — уникальный идентификатор заказа; 
- `guest_id` — идентификатор гостя; 
- `dish_id` — идентификатор блюда; 
- `quantity` — количество заказанных блюд.

### Назначение модулей

#### memory.py

Содержит основные классы предметной области и класс базы данных:

- `Guest` — описание гостя ресторана; 
- `Dish` — описание блюда;

- `RestaurantDB` — управление данными и выполнение операций над записями.

#### errors.py

Содержит пользовательские исключения:

## Обработка ошибок

В программе реализована обработка следующих ошибок:

- добавление записи с существующим идентификатором; 
- ввод отрицательной цены блюда; 
- ввод некорректного количества блюд в заказе; 
- попытка изменения или удаления несуществующей записи.

Для этого используются пользовательские исключения:

- `DuplicateRecordError`; 
- `RecordNotFoundError`.
