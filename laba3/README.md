# Лабораторная работа №3

Объектно-ориентированная in-memory СУБД для управления гостями, блюдами и заказами.

## Реализованная функциональность

* **ООП Архитектура:** База данных переписана с использованием классов (наследование от базового интерфейса `Table`). Внедрена собственная иерархия исключений для валидации.
* **TUI на классах:** Пользовательский интерфейс полностью инкапсулирован в класс `RestaurantUI`.
* **Сортировка и Фильтрация:** Реализована возможность фильтровать записи и сортировать данные по любому полю (по возрастанию/убыванию).
* **CRUD операции:** Поддержка создания, чтения, обновления и удаления записей.
* **Тестирование:** Логика базы данных покрыта автоматизированными unit-тестами с высоким процентом покрытия.

## Структура проекта

Все файлы размещены в корне проекта:

```text
/
├── src/
│   ├── db/
│   │   └── backend/
│   │       ├── errors.py   # Иерархия исключений БД
│   │       └── memory.py   # Классы таблиц
│   └── tui.py              # Класс интерфейса AppTUI
├── tests/
│   ├── __init__.py
│   └── test_memory.py      # Модульные тесты
└── README.md
```

## Инструкция по запуску

Для запуска приложения выполните следующую команду из корневой директории проекта:

```bash
cd src
python -m db
```

Запуск тестов и проверка покрытия (требуется установленный модуль pytest и pytest-cov):

```bash
python -m pytest tests --cov=src/db/backend --cov-report=term-missing
```
