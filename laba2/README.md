# Лабораторная работа №2

Данный проект представляет собой прототип базы данных, функционирующей в оперативной памяти, разработанный в рамках изучения механизмов коллекционных типов данных и ООП в Python.

## Описание реализованной функциональности

Приложение выполняет роль системы управления рестораном и поддерживает работу с тремя сущностями (таблицами):
1. **Гости (Guests)**
2. **Блюда (Dishes)**
3. **Заказы (Orders)**

**Реализованы следующие возможности (включая дополнительные задания на +2 балла):**
* **Полный CRUD:** Создание (Create), чтение (Read), обновление (Update) и удаление (Delete) записей для всех трех таблиц.
* **Архитектура:** Реализован общий интерфейс (базовый класс `Table`) для стандартизации работы с таблицами, что исключает дублирование кода.
* **Фильтрация:** Метод чтения поддерживает гибкую фильтрацию сразу по нескольким полям (AND-логика).
* **Валидация и обработка ошибок:** Система не позволяет добавлять записи с дублирующимися ID, блюда с отрицательной ценой или заказы, ссылающиеся на несуществующих гостей/блюда. Ошибки перехватываются и выводятся пользователю без падения приложения.
* **TUI:** Интерактивное консольное меню для удобного управления данными.

## Структура проекта

Все файлы приложения располагаются в корне проекта (без вложенных директорий вида `laba_X`):

```text
/
├── src/
│   ├── db/
│   │   └── backend/
│   │       └── memory.py   # ООП-ядро базы данных (классы таблиц, логика CRUD)
│   └── tui.py              # Консольный интерфейс взаимодействия с пользователем
└── README.md               # Описание проекта и инструкции
```

## Инструкция по запуску

Для запуска приложения выполните следующую команду из корневой директории проекта:

```bash
cd src
python -m db
```
