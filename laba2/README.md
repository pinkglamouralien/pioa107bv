
# Лабораторная работа №3

## Тема

Разработка прототипа базы данных ресторана, функционирующей в оперативной памяти (In-Memory Database).

## Цель работы

- Изучить принципы организации простых баз данных.
- Получить навыки работы с коллекциями языка Python.
- Освоить обработку исключений.
- Реализовать CRUD-операции для хранения данных в оперативной памяти.
- Разработать консольный интерфейс для взаимодействия с пользователем.

---

## Описание проекта

В рамках лабораторной работы реализована простая база данных ресторана, работающая в оперативной памяти без использования внешних СУБД.

База данных содержит три таблицы:

### Guests (Гости)

Хранит информацию о посетителях ресторана.

Поля записи:

- `id` — уникальный идентификатор гостя;
- `name` — имя гостя;
- `phone` — номер телефона.

### Dishes (Блюда)

Хранит информацию о блюдах ресторана.

Поля записи:

- `id` — уникальный идентификатор блюда;
- `name` — название блюда;
- `price` — стоимость блюда.

### Orders (Заказы)

Хранит информацию о заказах.

Поля записи:

- `id` — уникальный идентификатор заказа;
- `guest_id` — идентификатор гостя;
- `dish_id` — идентификатор блюда;
- `quantity` — количество заказанных блюд.

## Структура проекта

```text
src/

    │   ├── __init__.py

    │
```

### Назначение модулей

#### memory.py

Содержит:

- структуры данных таблиц;
- операции создания записей;
- операции чтения записей;
- операции обновления записей;
- операции удаления записей;
- обработку ошибок.

#### tui.py

Содержит консольный интерфейс пользователя.

#### __main__.py

Является точкой входа в программу.

## Реализованная функциональность

### CRUD-операции

Для таблиц **Guests**, **Dishes** и **Orders** реализованы следующие операции:

#### Create

Добавление новых записей.

#### Read

Просмотр записей.

Для таблицы Guests реализована фильтрация по имени.

#### Update

Изменение существующих записей.

#### Delete

Удаление записей.

---

## Обработка ошибок

В программе реализована обработка следующих ошибок:

- добавление записи с существующим идентификатором;
- ввод отрицательной цены блюда;
- ввод некорректного количества блюд в заказе;
- создание заказа для несуществующего гостя;
- создание заказа для несуществующего блюда;
- попытка изменения или удаления несуществующей записи.

---

## Используемые структуры данных

Для хранения данных используются:

- списки (`list`);
- кортежи (`tuple`);
- генераторы списков;
- функция `any()`.

Все данные хранятся в оперативной памяти и удаляются после завершения программы.
