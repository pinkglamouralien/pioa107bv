# Лабораторная работа №4

Приложение поддерживает хранение данных In-Memory (ОЗУ), а также работу с файловыми СУБД в форматах JSON и CSV.

## Описание архитектуры и различий
* **In-Memory (`memory.py`):** Базовая реализация классов таблиц. Данные хранятся в оперативной памяти в виде списков словарей. Используется как фундамент.
* **JSON и CSV (`json_db.py`, `csv_db.py`):** Файловые реализации. Построены с использованием механизма **наследования** от классов In-Memory, что устранило дублирование логики (CRUD, валидация) и сохранило единый публичный интерфейс. Эти реализации переопределяют мутаторы (create, update, delete) для автоматического сохранения структуры и записей на диск.
* Обеспечен перехват специфических файловых исключений (`FileStorageError`) без падения системы.

## Структура проекта

```text
/
├── data/                   # Директория для хранения JSON и CSV файлов
├── src/
│   ├── db/
│   │   └── backend/
│   │       ├── errors.py   # Иерархия исключений (вкл. FileStorageError)

│   │       └── csv_db.py   # СУБД для формата CSV

│   ├── __init__.py
│   ├── test_memory.py      
│   ├── test_json.py        # Тесты файловой системы JSON
│   └── test_csv.py         # Тесты файловой системы CSV
└── README.md
```
## Инструкция по запуску

Для запуска приложения выполните следующую команду из корневой директории проекта:

```bash
cd src
python -m db
```

Запуск тестов и проверка покрытия (требуется установленный модуль pytest и pytest-cov):

```bash
python -m pytest tests --cov=src/db/backend --cov-report=term-missing
```
